Práctica de Posiciones en CSS 📌

Esta práctica se desarrolló siguiendo la guía de freeCodeCamp. La propiedad position en CSS define cómo se posiciona un elemento en el documento.

1. Position: Static (Estático)

Es la posición por defecto de todos los elementos HTML. Sigue el flujo normal de la página y no acepta las propiedades top, bottom, left o right.

Caja con Position Static

2. Position: Relative (Relativo)

El elemento se posiciona relativo a su ubicación normal original. Al desplazarlo con top o left, el espacio original que ocupaba se conserva.

Caja con Position Relative (top: 10px, left: 20px)

3. Position: Absolute (Absoluto)

El elemento se remueve del flujo normal y se posiciona de forma absoluta respecto al contenedor padre más cercano que tenga un posicionamiento distinto a static.

Contenedor Padre (Relative)
Caja Absolute (top: 10px, right: 10px)

4. Position: Fixed (Fijo)

El elemento se posiciona respecto a la ventana del navegador (viewport). Se mantiene fijo en el mismo lugar aunque el usuario desplace la página (scroll).

Caja Fixed (Esquina inferior derecha)

5. Position: Sticky (Pegajoso)

Combina relative y fixed. Se comporta como relativo hasta que se alcanza un umbral al hacer scroll, momento en el que se "pega" en la pantalla.

Caja Sticky (Se fija al hacer scroll)
