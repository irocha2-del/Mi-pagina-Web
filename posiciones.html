Práctica de Posiciones CSS (freeCodeCamp) 📌

Demostración directa de las reglas de posición aplicadas a cajas de 100x100 px.

1. Position: Static

Las cajas se colocan una debajo de otra en el flujo normal.

Normal

2. Position: Relative

La caja naranja aplica position: relative; top: 30px; left: 40px; moviéndose desde su posición original.

Relative

3. Position: Absolute

El contenedor padre tiene position: relative. La caja naranja tiene position: absolute; top: 10px; right: 10px; y la azul sube.

Normal

4. Position: Fixed

La caja verde aplica position: fixed; bottom: 20px; right: 20px; y se fija abajo a la derecha de tu pantalla.

Fixed

5. Position: Sticky

Haz scroll hacia abajo dentro del recuadro gris: la caja naranja tiene position: sticky; top: 0; y se queda pegada al borde superior.
